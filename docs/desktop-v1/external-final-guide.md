# RC3 独立设备最终验收

使用新的 `AntennaDraw-Setup-1.0.0-rc.3-x64.exe`，不要再运行 alpha.2、RC1 或 RC2 的安装自检。安装包未签名；核对交付 SHA-256 后从普通用户安装开始。测试机无需 Node.js 和源码，需要有效 MATLAB 许可。

## 自动技术检查

1. 安装并从桌面 AntennaDraw 快捷方式打开。完成首次引导：选择 MATLAB、保存并检测、使用演示数据。
2. 等待所有检测/绘图结束，打开顶部“安装自检 → 运行安装自检…”。选择 MATLAB 及报告保存目录。
3. 如设备确无 Node.js/源码，在确认窗口选择相应选项。等待结果窗口显示 PASS/FAIL；不要只看安装成功。
4. 打开三张 sample PNG，逐项核对标题、轴标、色标、叠加与尺寸，尤其检查 SCR 标题上方没有工具栏。
5. 进入 reports 子目录的 downloads，打开下载 PNG，并实际解压 figures.zip，确认三张图能打开且与样图一致。
6. 完整关闭应用，断网，从桌面快捷方式重开，再运行自检；记录断网与重启动作。自动报告不能证明这两个手工动作。

## 实际界面和异常检查

- 使用允许测试的真实数据副本：室内/室外、多任务与多层、对比统一坐标、三种坐标方式、调色、连续指标分析。对照已有可信结果，不增加新统计口径；BESTSERVER 继续保留类别绘图。
- 从实际界面保存 PNG、ZIP、CSV 和交互/分析 Canvas PNG；打开文件核对内容。取消保存应静默，保存失败不能显示“已保存”。
- 分别选择源目录旁和独立输出；切换设置后从任务记录打开历史位置。只读源使用独立可写结果根；只对专门的测试副本设置权限，不改业务目录 ACL。
- 检查不存在的 MATLAB 路径、无 MATLAB、磁盘不可写/空间不足等可安全提供的场景。真实许可不可用时记录真实错误；不要修改正常许可文件制造故障。
- 绘图开始后取消、关闭时选择留在应用/取消并退出；必要时用测试任务做超时或强退重启，确认中断不自动重跑、用户另开 MATLAB 不受影响。
- 移动测试数据副本并从界面重新定位；用测试用户根检查坏配置恢复、较新 schema 拒绝降写。升级/卸载/重装及 Dev 共存使用隔离测试数据。

每项填写 PASS、FAIL 或未执行，失败附错误文字和截图。尚未实际执行的项目保留“未执行”。不要以截图或旧版本报告推定新版本通过。

请带回**整个自检报告文件夹**（含 acceptance-report.json、sample PNG、downloads 和验收结果.html）、已填写的 final-manual-results.md，以及必要的错误截图。无需带回真实输入 DEM 或 MATLAB 许可。诊断在设置中预览后导出。

只有最终候选的独立设备完整验收与问题闭环完成，才能确认正式 1.0.0；源码测试、构建成功和旧版验收均不能代替。
