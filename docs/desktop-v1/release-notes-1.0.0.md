## 功能

- Windows 当前用户安装、桌面快捷方式、本地 Electron 运行时；安装使用者无需 Node.js、源码或命令行。
- MATLAB 路径选择、保存、真实能力检测、首次引导和合成演示数据。
- 配置和色标/分析偏好持久化，稳定/开发渠道独立用户根，主动导入旧配置与数据源重新定位。
- 任务队列、取消、超时、逐图部分失败、失败重试及重启中断记录；仅终止本次所属 MATLAB 进程。
- 两种结果位置、完整 PNG 验证后的原子发布、跨实例输出锁、历史任务下载和打开目录。
- PNG/ZIP/CSV/Canvas 原生保存反馈；安全会话、受限 IPC、导航限制、限量日志和诊断预览。
- 保留既有绘图、对比、坐标、调色与连续指标分析语义；导出图片关闭工具栏。

## 安装与升级

普通使用者使用交付目录根部 AntennaDraw-Setup-1.0.0-x64.exe。已安装 RC3 时，完整关闭应用后在原位置覆盖安装；配置、数据源、偏好和历史结果按现有数据根继续使用。开发测试包位于“开发测试”子目录，名称含 Dev，数据根与稳定版分开。

两包未签名，使用前核对交付目录 SHA256SUMS.txt。目标平台为 Windows 11 x64，MATLAB 由用户自备有效许可。本机为 R2022a；同代码 RC3 在外机 R2024b 的两轮技术自检、样图及 ZIP 通过，用户确认重开及离线本地 RSRP 正常。完整证据边界见 acceptance-report.md 和 support-matrix.md。
