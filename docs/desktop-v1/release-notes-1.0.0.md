# Desktop V1 1.0.0-rc.3 候选说明

本文件保留计划约定名称，当前交付版本为 **1.0.0-rc.3**，并非正式 1.0.0。最终独立设备完整验收仍待完成；alpha.2 的外机证据不能覆盖此候选。

## 本轮功能

- Windows 当前用户安装、桌面快捷方式、本地 Electron 运行时；安装使用者无需 Node.js、源码或命令行。
- MATLAB 路径选择、保存、真实能力检测、首次引导和合成演示数据。
- 配置和色标/分析偏好持久化，稳定/开发渠道独立用户根，主动导入旧配置与数据源重新定位。
- 任务队列、取消、超时、逐图部分失败、失败重试及重启中断记录；仅终止本次所属 MATLAB 进程。
- 两种结果位置、完整 PNG 验证后的原子发布、跨实例输出锁、历史任务下载和打开目录。
- PNG/ZIP/CSV/Canvas 原生保存反馈；安全会话、受限 IPC、导航限制、限量日志和预览脱敏诊断。
- 保留既有绘图、对比、坐标、调色与连续指标分析语义；显式关闭导出工具栏。

## RC3 安全修订

生产依赖锁定 body-parser 1.20.9、qs 6.16.1、source-map-js 1.2.2。2026-10-31 后端和前端 npm 生产依赖审计均为 0 项已知漏洞；66 项单测和 9 项 Electron 集成通过。这不是对未知漏洞的保证。RC1、RC2 仅为中间测试产物，不用于交付。

## 使用与限制

普通使用者安装 stable 渠道的 AntennaDraw-Setup-1.0.0-rc.3-x64.exe；Dev 安装包仅供开发测试。两包未签名，均需核对交付清单 SHA-256。实际本机验证和待验收项目见 acceptance-report.md；环境版本与边界见 support-matrix.md。

当前没有自动更新、账号、许可准入或云服务。MATLAB 由用户自备有效许可；不支持凭安装包绕过 MATLAB 许可。安装和卸载默认保留用户配置、输入数据与结果，手动升级前建议备份用户数据根。

独立设备需使用本次最终候选完成完整验收，带回整个报告目录（含 downloads）、手工结果表及必要错误截图。R2024b 工具栏导出复核和真实案例等未执行项不得标为通过。本轮仅准备本地交付，不推送、不合并、不发布 GitHub Release。
