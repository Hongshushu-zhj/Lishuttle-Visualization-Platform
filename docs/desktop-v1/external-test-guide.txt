另一台 Windows 设备：阶段 A 安装验收
=================================

这是 Desktop V1 的开发候选，不是正式版。它用于确认桌面安装、包内运行时和真实 MATLAB 绘图可用。

设备准备
--------
1. 使用 Windows 11 x64、普通 Windows 用户账户。
2. 该设备已经安装并能正常使用 MATLAB，且许可有效。首个验证目标为 R2022a；其他版本请如实反馈。
3. 无需安装 Node.js、npm，也不要复制项目源码。若测试机本来已有 Node.js，仍可复测，但不能记为“无 Node.js 环境通过”。

怎么测试（全程不需要输入命令）
----------------------------
1. 把本测试压缩包复制到另一台电脑并解压。
2. 双击其中的 AntennaDraw-Dev-Setup-1.0.0-alpha.2-x64.exe，按向导以当前用户安装。
3. 从桌面图标打开 AntennaDraw Dev。
4. 点击窗口上方“安装验收”菜单，再点“运行阶段 A 安装验收…”。
5. 选择该电脑 MATLAB 安装目录中的 bin/matlab.exe。
6. 选择一个可写文件夹保存报告，然后按实际情况回答“是否未安装 Node.js 且没有复制源码”。
7. 等待完成。工具只用包内合成小样本，会检查统计线程、室内 RSRP、室外 SCR、BESTSERVER 三张图，以及 PNG/ZIP 保存。
8. 结果窗口显示 PASS 或 FAIL。点击“打开报告文件夹”，保留 acceptance-report.json 和 sample-1.png、sample-2.png、sample-3.png。

MATLAB 首次启动可能需要几分钟。原型尚未实现正式任务取消和超时监管；验收进行时请等待，不强行结束应用。选择文件或报告目录时可以取消，取消不会更改已有数据源。

还要人工查看
------------
- 三张 sample PNG 都能打开，标题、坐标、色标和室内墙线正常。
- downloads/ 中 sample-download.png 能打开；figures.zip 能解压且包含三张图。
- 如果 MATLAB 许可允许离线使用，请断网后重新运行一次安装验收；需要在线许可时如实说明，不改动许可配置。
- 关闭所有测试窗口，重新从桌面图标打开，确认正常启动。
- 如有弹窗、空白页或错误，请保存截图并描述发生步骤。

请带回什么
----------
1. acceptance-report.json。
2. 三张 sample PNG；有错误时再附截图。
3. 简单说明：Windows 版本、MATLAB 是否有效、是否确实没有 Node.js/源码，以及上述人工检查的结果。

报告不会自动上传。报告包含系统与软件版本、各项检查结果和合成样本统计，不包含会话凭证、MATLAB 许可内容或业务 DEM。报告目录内的 synthetic-demo 都是合成数据。

注意
----
本包未签名，只是开发候选。尚未实现 MATLAB 正式设置页、任务取消/超时、升级共存等后续内容。普通主界面的“开始绘图”目前还不是最终用户配置流程；这次请使用“安装验收”入口。

自动检查 PASS 只表示本次阶段 A 自动检查通过；干净设备、图片人工查看、断网和重启结果仍需一起确认。不要把这个结果当成整个 Desktop V1 已完成。
