# Task 4：MATLAB 检测和所属进程监管

执行日期：2026-10-31（北京时间）。基于 Task 3 的用户数据和设置接口继续开发。

## 实现

- MATLAB 路径校验、有限常见安装目录发现、显式点击后启动真实能力检测；检测 180 秒超时，支持取消，与绘图共享单槽位。
- 微型合成室内 RSRP / 室外 SCR 数据调用原绘图程序，检查实际版本、能力报告和 PNG；检测指纹包含 MATLAB 可执行文件及受信任 MATLAB 脚本内容，文件变化后重新检测。
- 受监管 executable/args 独立传递，固定可信 cwd、清理非必要运行环境变量、私有 MATLAB 偏好目录。增量解析协议，包含分块、无尾换行、重复/越界序号和不完整结果。
- Windows C# 守护进程用 Windows Job Object 在创建目标进程时原子建立归属；只终止本次 Job，确认 ActiveProcesses=0 才返回 cleanupConfirmed。服务崩溃时命名管道断开触发所属进程清理，恢复只接受所属结果或明确重启证据，不按进程名/历史 PID 清理。
- 无法确认退出则保留归属标记并阻止下一任务。日志内存尾部限量。原生 MATLAB 文件选择与界面在 Task 5 接入，退出交互及持久化任务状态在 Task 6 完成。

## 已运行证据

- Node 流程测试：实际 Windows 父子进程的参数、独立 sentinel 不受影响、取消、超时、父进程早退、服务崩溃后恢复、未确认归属禁止放行；环境发现、错误分类与取消状态；绘图协议测试。
- 本机真实 MATLAB `9.12.0.1884302 (R2022a)`，路径 `D:/Matlab/R2022a/bin/matlab.exe`：微型真实能力检测通过；另启真实 MATLAB 后取消和超时均确认所属进程退出。测试资源和数据目录包含中文、空格、单引号。证据在忽略的 `.desktop-test-data/matlab-environment-real.json`。
- 源码 Electron utilityProcess 内真实统计线程、MATLAB 室内/室外/BESTSERVER 三图、PNG 解码与 PNG/ZIP 下载五项 PASS；数据 mean=-90、validCount=3、2 层、绘图 3 成功 0 失败。
- 原七条隔离基线均 exit 0；前端模型 10/10 通过。
