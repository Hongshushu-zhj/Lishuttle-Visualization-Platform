# 仿真结果数据分析模块 · 方案(待评审,暂不实施)

> 目标:对 RSRP / SCR / ECHORP 等仿真结果图做**自动化、可解释**的分析:指出问题区域、
> 判定问题成因、给出与工参设置结合的改进建议。本文只描述方案,评审通过后再开发。

---

## 0. 设计原则

1. **判据可追溯**:每个门限都标注来源(3GPP 标准条款 / 行业实践 / 雷达检测理论),不用"拍脑袋"数值;
   门限集中放在可编辑的规则文件里,你可以覆盖。
2. **结论有证据**:每条结论都带数据证据(区域编号、面积占比、百分位、统计量),不做主观判断。
3. **不越界**:分析只基于仿真数据与工参文件的客观关系;涉及需硬件/现场信息(馈线损耗、实际遮挡、
   测试数据)的判断,只提示"需现场核实",不硬下结论。
4. **纯计算、不占 MATLAB**:栅格解析与统计在 Node 侧完成(平台已有 .dem 解析规则),
   分析可与绘图并行,不排队等 MATLAB;只有需要"标注版地图"时才调用现有渲染脚本。

## 2. 判据与门限(来源分类,便于你审校)

### 2.1 RSRP / SINR —— 有标准依据

| 项 | 内容 | 来源 |
|---|---|---|
| RSRP 定义 | SS-RSRP:承载 SSS 的 RE 功率线性平均 | 3GPP **TS 38.215** §5.1 |
| RSRP 上报范围 | **-140 ~ -44 dBm**,1 dB 步长(RSRP_0…RSRP_127) | 3GPP **TS 38.133** 表 10.1.4.1-1 |
| SINR 上报范围 | SS-SINR **-23 ~ +40 dB**,0.5 dB 步长 | 3GPP **TS 38.133** 表 10.1.16.1-1 |
| 弱覆盖门限(行业) | -105 dBm 常用判定门限;<-110 dBm 视为极弱/空洞;<-100 dBm(连续 50m)判弱覆盖 | 运营商外场优化实践、规划专利文献 |
| 质差判定(行业) | RSRP > -110 dBm 且 SINR < -3 dB | 同上 |
| 覆盖率 | 满足 RSRP ≥ 门限的**栅格占比 ≥ 95%** | 网络规划通用判据 |

> 说明:标准只定义"怎么测、怎么报";**多强算好**属于规划门限,来自行业实践,我会把它作为可调参数
> 而不是"标准规定值"。

### 2.2 SCR —— 无 3GPP 门限,用检测理论推导

SCR(信杂比)**不是** 3GPP 定义的网络指标。3GPP 的通感工作(Rel-19)目前给出的是
**用例与需求**(TR 22.837、TS 22.137:KPI 含感知精度、检测时延、空间分辨率)与
**信道模型**(TR 38.901 Rel-19 ISAC 扩展、TR 38.857:目标 RCS、单站/双站模型),**没有 SCR 门限标准**。

因此本模块的做法是:**按检测理论算出所需 SCR**,而不是写死一个数:

- 采用 Albersheim 公式(单脉冲)与 Shnidman 公式(可含积累),由你给定
  **检测概率 Pd、虚警概率 Pfa、脉冲积累数 N**,自动算出所需 SCR 门限。
- 校验示例(可复算):Pd = 0.9、Pfa = 1e-6、N = 1、Swerling I → 所需 ≈ **13.1 dB**
  (Albersheim:SNR ≈ [6.2 + 4.54/√(N+0.44)]·log10[A + 0.12AB + 1.7B],A = ln(0.62/Pfa),B = ln(Pd/(1-Pd)))。
- 由此把 SCR 图翻译成**三档结论**:满足检测门限 / 处于边缘(门限 -3 dB 内)/ 不满足,
  并给出各档面积占比。

> 需要你确认:你仿真里 **SCR 的物理定义**(目标回波功率 ÷ 杂波功率?是否含噪声?单站还是双站?
> 杂波是否只含建筑/地物反射)。定义不同,门限的物理含义不同,这一步确认后方案才算闭合。

### 2.3 ECHORP —— 用链路预算转成"检测余量"

ECHORP(回波接收功率)是绝对功率,dBm。分析方式:

```
检测余量(dB) = ECHORP - 噪声底 - 所需信噪比
噪声底 = -174 + 10·log10(BW) + NF     (dBm,需你提供接收带宽 BW 与噪声系数 NF)
所需信噪比 = 由 2.2 的 Pd/Pfa/N 计算
```

- 结论形式:"某区域 ECHORP 高于检测门限 X dB,具备检测条件"/"低于门限 X dB,不可检测",
  并输出**余量分布图**(把 dBm 图翻译成可判读的余量图),这比看原始 dBm 直观。
- 若你能提供目标 RCS 与传播模型参数,还可反推**理论探测距离**做交叉验证。

## 3. 分析方法

### 3.1 统计与分布
- 有效栅格占比(剔除 `-32768`)、均值/标准差、P5/P50/P95;
- CDF 曲线、直方图;按高度层的分布箱线图;
- **数据完整性检查**:无效值成片出现(可能未覆盖仿真边界)会被单独提示,避免把"无数据"误判为"弱覆盖"。

### 3.2 空间问题区域识别(输出"问题清单",不是只出一张图)
1. 阈值分割(门限可调)→ 得到"不满足区"栅格掩膜;
2. **连通域标记**(8 邻域)→ 每个独立区域计算:面积、质心坐标(UTM)、最长延伸方向、
   到最近基站的距离与相对方位;
3. 区域分级:**A 级**(面积大且指标极差)、**B 级**(边缘区、可能误判)、**C 级**(零星栅格,先观察);
4. 输出问题区域清单(编号 R1/R2…),后续所有结论都引用这些编号,便于与优化人员对齐。

### 3.3 交叉指标判因(关键:区分"覆盖不足"还是"干扰受限")

| 组合 | 判读 | 建议方向 |
|---|---|---|
| RSRP 差 + SINR 差 | 覆盖不足 | 功率/下倾/方位角/补点 |
| RSRP 好 + SINR 差 | **干扰受限 / 导频污染 / 越区** | 下倾角加大、方位角错开、功率下调 |
| RSRP 差 + SINR 好 | 覆盖边缘,但干扰小 | 提升覆盖即可,射频参数微调 |
| SCR 好 + RSRP 差 | 杂波小但信号弱 | 与通信覆盖同向优化 |
| SCR 差 + RSRP 好 | **杂波主导**(低空/密集建筑/地物反射强) | 波束指向、抗杂波处理、抬高旁瓣抑制 |
| ECHORP 高 + SCR 低 | 收到强回波但目标是"淹没在杂波里" | 需从波形/处理增益入手,而非加大功率 |

> 这张表是整个分析模块的核心价值:把"图不好看"变成"该动哪个参数"。

### 3.4 垂直维度分析(平台独有:11 个高度层)
- 指标随高度的曲线(平均 RSRP–高度、SCR–高度)、各层覆盖率对比;
- 自动标记**异常层**:如地面达标但 60m 以上快速劣化 → 指向**下倾角偏大 / 垂直波束宽度不足**;
- 低空(10~30m)SCR 明显低于高空 → 指向**地物/建筑杂波**;
- 该维度是普通路测分析做不到的,也是通感(无人机/低空场景)最关心的。

### 3.5 小区级分析(用 BESTSERVER)
- 各小区实际覆盖面积、形状是否与天线方位角一致;
- **越区覆盖**:某小区在其方位角 ±60° 之外仍为主导 → 疑似下倾不足/功率过高;
- **重叠度**:相邻小区主导区重叠比例过高 → 导频污染风险;
- 覆盖率按小区排名,直接列出"问题小区 Top N"。

## 4. 工参联动分析(可选,需要你提供工参文件)

### 4.1 工参文件要求(模板我会给出,你按列填写即可)

| 字段 | 必需 | 说明 |
|---|---|---|
| 站名 / 小区名 | ✔ | 与 BESTSERVER 的小区编号对应关系需一并提供 |
| 经度 / 纬度(WGS84) | ✔ | 平台按 `UTM <zone>` 自动互转(zone 49 → EPSG:32649) |
| 挂高(m) | ✔ | 用于下倾角几何计算 |
| 方位角(°)/ 机械下倾(°)/ 电子下倾(°) | ✔ | 判定主瓣指向与调整量 |
| 发射功率 / 天线增益 | ✔ | 判断功率手段是否还有余量 |
| 水平/垂直波束宽度 | 建议 | 调整量计算与边缘覆盖评估 |
| 天线型号、场景(城区/郊区) | 可选 | 约束建议(城区避免增功率导致干扰) |

> 也可直接给 UTM 坐标,省去转换;格式 CSV 或 Excel 均可,字段名我按你的实际文件适配。

### 4.2 判定规则(问题区域 ⟷ 工参几何关系)

| 现象 | 几何关系 | 疑似原因 | 建议动作(含初值) |
|---|---|---|---|
| 区域内 RSRP 差 | 落在某站主瓣 ±30° 内、距离在合理站间距内 | 功率不足 / 下倾过大 / 遮挡 | 先查功率余量;必要时减小下倾 |
| 区域位于两站之间,SINR 差而 RSRP 尚可 | 双站主瓣交叠 | 重叠过多、导频污染 | 加大下倾或方位角错开,降低交叠 |
| 区域在站点背向(>±60°)仍弱 | 主瓣未覆盖 | 覆盖盲区 | 方位角对准(Δa = arctan(Δlon/Δlat) − a_old)或补点 |
| 某小区远距离仍主导 | 超出其方位覆盖 | 越区覆盖 | 下倾角加大 / 功率下调 |
| 低空 SCR 差而 RSRP 好 | 站点近、俯角大 | 地物杂波主导 | 调整波束下压/旁瓣抑制,而非加大功率 |

**下倾角几何初值**(供参考,最终需仿真复算):
`θ_new = arctan(Δh / d) + β/2`(Δh 挂高差,d 到目标距离,β 垂直波束宽度)

### 4.3 建议输出形式

一条建议 = **问题区域编号 + 数据证据 + 涉及站点/小区 + 建议动作 + 参考调整量 + 风险提示**。
例:

> R3(`742980, 2561450`,面积 1.2 万 m²,RSRP P50 = -112 dBm,SINR P50 = 8 dB)
> 位于 A 站(方位角 30°)正前方 380m,该方向挂高 25m、当前下倾 8°。
> 判读:覆盖不足型;RSRP 低于弱覆盖门限 7 dB,SINR 良好说明非干扰问题。
> 建议:优先核查该小区发射功率是否受限;若已满功率,考虑下倾减至 5°~6° 或增补站点。
> 风险:下倾减小会扩大该站覆盖,需复查与相邻 B 站的重叠(当前重叠度 38%,偏高)。

## 5. 输出物

1. **图侧分析卡**:每张图附"统计摘要 + 关键发现 3~5 条";
2. **标注版地图**:在原图上叠加问题区域框选、编号、基站主瓣射线(调用现有 MATLAB 渲染 + 叠加层);
3. **综合分析报告**(单页 HTML,可打印为 PDF):含结论汇总、问题清单、图例;
4. **问题区域清单 CSV**:编号/坐标/面积/指标/分级/判因,可直接交给优化人员;
5. **工参调整建议表**(有工参时):站点/参数/当前值/建议值/依据/优先级/风险。

## 6. 实现架构(嵌入现有平台)

```
platform/backend/src/analysis/
├─ raster.js        栅格读取与统计(复用现有 .dem 解析规则)
├─ thresholds.js    门限计算(含 Albersheim / Shnidman 检测门限)
├─ regions.js       阈值分割 + 连通域 + 区域特征
├─ correlate.js     交叉指标判因(3.3 的表落成规则)
├─ vertical.js      高度层曲线与异常层标记
├─ cells.js         小区级分析(BESTSERVER)
├─ params.js        工参文件解析 + UTM/经纬度转换 + 几何判定
├─ advise.js        建议生成(规则 + 模板化文本)
└─ report.js        HTML/CSV 报告产出

analysis-rules.json  ← 门限与规则集中配置(可编辑,含来源注释)
```

- **API**:`POST /api/analysis/run`(源 + 类型 + 层 / 或"全部层")→ `GET /api/analysis/:id`
  (JSON 结果)→ `/report`(HTML)、`/regions.csv`、`/overlay.png`(标注图)。
- **前端**:新增「分析」页 —— 选源与类型 → 门限设置(默认按规范、可覆盖)→ 运行 →
  报告视图(摘要卡 / 标注图 / 区域表 / 建议表),支持导出。
- **性能**:单层 1535×1465 ≈ 225 万栅格,连通域与百分位在 Node 中为毫秒~秒级;
  11 层全量分析预计数秒内完成,不占用 MATLAB。

## 8. 需要你确认的问题(确认后即可开工一期)

1. **SCR / ECHORP 的物理定义**:SCR = 回波 ÷ 杂波 还是 ÷(杂波+噪声)?单站还是双站?
   杂波是否只含建筑/地物反射?(决定门限物理含义)
2. **工参文件**:能否提供一份样例(字段名与格式)?小区编号与 `BESTSERVER` 的对应关系如何确定?
   坐标是经纬度还是 UTM?
3. **场景与 KPI 目标**:通感主要面向什么目标(无人机 / 车辆 / 人员)?可接受的
   Pd / Pfa / 积累脉冲数是多少?(用于算检测门限)
4. **是否需要干扰维度输入**:若你有邻区/干扰源或其它方案的结果文件夹,可做"干扰贡献"对比分析。
5. **分析语言与深度**:报告是给优化人员看的操作清单,还是给项目验收用的结论报告?
   (影响报告结构与术语粒度)
